# C++ Modules (00 à 09)

Parcours des modules C++ de l'école 42, en norme C++98 (sauf module 09 selon le sujet). Chaque dossier contient les exercices du module correspondant.

| Module | Thème | Notions clés |
|--------|-------|--------------|
| cpp00 | Bases du C++ | Namespaces, classes, fonctions membres, flux d'entrée/sortie (`iostream`), initialisation, `static`, `const` |
| cpp01 | Mémoire et références | Allocation sur la pile et le tas (`new`/`delete`), pointeurs, références, pointeurs sur fonctions membres, `switch`, flux de fichiers |
| cpp02 | Polymorphisme ad hoc | Surcharge d'opérateurs, forme canonique de Coplien, nombres à virgule fixe |
| cpp03 | Héritage | Héritage simple et multiple, constructeurs et destructeurs chaînés, encapsulation (`protected`) |
| cpp04 | Polymorphisme de sous-type | Fonctions virtuelles, classes abstraites, interfaces, copie profonde |
| cpp05 | Exceptions | Blocs `try`/`catch`, classes d'exceptions personnalisées, `std::exception` |
| cpp06 | Conversions de types | Les quatre casts C++ (`static_cast`, `dynamic_cast`, `reinterpret_cast`, `const_cast`), conversion de types scalaires, sérialisation |
| cpp07 | Templates | Fonctions et classes génériques, spécialisation, templates de tableaux |
| cpp08 | Conteneurs et algorithmes STL | Conteneurs (`vector`, `list`, `stack`), itérateurs, algorithmes `<algorithm>` |
| cpp09 | STL avancée | Choix du conteneur adapté, parsing de fichiers, calculatrice en notation polonaise inversée, algorithme de tri Ford-Johnson (merge-insertion) |

## Compétences transversales
- Programmation orientée objet complète
- Gestion de la mémoire et des ressources (RAII)
- Programmation générique
- Bibliothèque standard (STL)
- Makefile et compilation avec `-Wall -Wextra -Werror -std=c++98`
